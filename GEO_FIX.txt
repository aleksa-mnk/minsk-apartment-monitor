Исправление геолокации и валют для Kufar + Realt.

- Более надёжный выбор полного адреса вместо метки «Минск».
- Поиск геокоординат в распространённых вложенных форматах выдачи.
- Цена в BYN сравнивается с бюджетом в USD только по официальному курсу НБРБ.
- Для времени пешком 25–45 минут расширяется OSM-индекс адресов.
- В логах GitHub Actions строки SOURCE: получено, нет координат, рядом,
  пешие маршруты, прошли время/бюджет/все фильтры.
- Ручная проверка присылает короткий итог Kufar / Realt / Onliner.
- По умолчанию просматриваются до 8 страниц источника.

Установка: распаковать архив в корень существующего проекта с заменой файлов,
затем выполнить git add и git commit, после чего git push origin main.

Проверка после запуска GitHub Actions:
Check listings and notify on Telegram -> поиск в логе 'SOURCE Kufar',
'SOURCE Realt' и 'SOURCE Onliner'.

Диагностика прямо на Windows без Telegram-токена:
  .\.venv\Scripts\python.exe diagnose_sources.py

Важно: реальные ответы источников и работу GH Actions надо подтвердить после
обновления. При отсутствии точного местоположения бот не выдумывает пеший путь.
